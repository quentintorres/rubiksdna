# Coefficient and reference data provenance

Nothing in this directory was produced by RUBIKS DNA. Every file is an
unmodified or mechanically filtered copy of published data, recorded here so
any value the product emits can be traced to its source.

## horvath2013.raw.csv

- Model: Horvath multi-tissue epigenetic clock, 353 CpGs.
- Published: Horvath S., "DNA methylation age of human tissues and cell types",
  Genome Biology 2013, 14:R115 (open access), Additional file 3.
- Obtained from: the biolearn project's redistribution of the published
  coefficients, https://github.com/bio-learn/biolearn (file `biolearn/data/Horvath1.csv`),
  downloaded 2026-08-31.
- Intercept 0.695507258 and the age transform (adult_age = 20) are from the
  same publication and live in code (`src/registry.ts`, `src/engine.ts`).

## hannum2013.raw.csv

- Model: Hannum whole-blood clock, 71 CpGs, no intercept, no transform.
- Published: Hannum G. et al., "Genome-wide methylation profiles reveal
  quantitative views of human aging rates", Molecular Cell 49, 359-367 (2013),
  supplementary table.
- Obtained from: https://github.com/bio-learn/biolearn (file `biolearn/data/Hannum.csv`),
  downloaded 2026-08-31.

## imputation_reference_450k.csv

- Per-probe median beta values from the sesame R package's 450k reference,
  as redistributed by biolearn (`biolearn/data/sesame_450k_median.csv`),
  filtered to the 418 probes required by the registered clocks.
- Regenerate by re-running the filter against the union of registry probes if
  a clock is added (see git history of this file for the original command).

## Golden test data (../__tests__/golden)

- Input: 10 whole-blood 450k samples from GEO series GSE41169
  (Horvath 2013's evaluation data), restricted to the 418 registered clock
  probes. Produced by `scripts/build-golden-fixture.py` from
  `GSE41169_series_matrix.txt.gz` fetched from the NCBI GEO FTP.
- Expected outputs: published reference values from the biolearn test suite
  (`biolearn/test/data/expected_model_outputs/{Horvathv1,Hannum}.csv`),
  generated by an independent implementation of the same published models.
- Tolerance: 1e-5 years, matching the reference project's own golden
  tolerance for these models.
